// ============================================
// Blessing Galgame Engine —— 演示剧本 3（BGalS v2）
// 演示：scene mount/unmount、trans 转场、wait 等待、char wait:true、
//       v2.1/v2.2 音频（sfx loop 环境音、music volume、sfx stop、
//       fade_in/fade_out 交叉淡变拆分、sfx volume）
// ============================================

bg demo_stage
music demo_bgm loop:true

// 挂载一个 UI 场景作为演出层（MessageUI 仅为演示可挂载性）
scene mount ui 演出层 res://Scenes/OptionUI/option_ui.tscn time:0.5

引路人: 这个剧本演示场景挂载、转场与等待指令。

// 转场：wait:true 挂起剧情直到转场完成
trans out time:0.5 wait:true
trans in time:0.5 wait:true

引路人: 刚才画面暗下又亮起——trans wait:true 会等转场播完。

// wait：剧情停顿一秒（点击可打断）
wait 1.0

引路人: 刚才停顿了一秒。

// v2.1 音频：环境音循环、在播曲目调音量、按引用停止（演示暂借 BGM 资源充当音效）
sfx demo_bgm volume:0.15 loop:true
引路人: 这层低低的循环底噪来自 sfx loop:true——环境音用法。
music volume 0.4 fade:0.8
引路人: BGM 压暗了——music volume 调节在播音轨，不重启曲目。
sfx stop demo_bgm fade:0.5
music volume 1.0 fade:0.8
引路人: 环境音停止，BGM 恢复全量。

// v2.2 音频：交叉淡变「快出慢进」（fade_in/fade_out 拆分）、在播音效调音量（渐强不中断）
music demo_bgm_2 fade_out:0.3 fade_in:2.0
引路人: 旧曲快退、新曲缓缓漫上来——fade_in 与 fade_out 分开控制的交叉淡变。
sfx demo_bgm volume:0.15 loop:true
sfx volume demo_bgm 0.4 fade:1.5
引路人: 环境音渐渐变响了——sfx volume 不中断播放地调节在播音效响度。
sfx stop demo_bgm fade:0.5

// char wait:true：等立绘移动完成才继续
char 0 setup demo_char_a 0.3,0.95
char 0 show time:0.4 wait:true
引路人: 立绘淡入完成后这句话才出现。

char 0 move 0.7,0.95 time:0.5 wait:true
引路人: 移动完成后剧情才继续。

// 卸载演出层
scene unmount ui 演出层 time:0.3 free:true

引路人: 演示到此结束。
jump main_menu
