# docs —— 设计文档索引

本目录收录 Blessing Galgame Engine 的设计与分析文档。面向使用者的入口文档在仓库根目录：

- [README.md](../README.md) —— 项目门面：特性、运行要求、快速开始
- [GalSGrammar.md](../GalSGrammar.md) —— BGalS 剧本语言规范（编剧向，以代码为准）
- [ROADMAP.md](../ROADMAP.md) —— 开发路线图与待实现能力

## 本目录文档

| 文件 | 内容 |
| --- | --- |
| [项目分析.md](项目分析.md) | 从 Godot 运行角度拆解现行实现：启动流程、剧情执行、对话与输入、画面表现、选项与条件分支、资源加载、文本导入、存档读档、音频系统 |
| [架构及其优化方案.md](架构及其优化方案.md) | 当前架构的分层描述与优势分析，以及面向规模扩大的演进建议（文档化、指令对照表、资源索引、缓存、存档版本化、UI 主题化等） |
| [架构评估与竞品对比分析.md](架构评估与竞品对比分析.md) | 与 Ren'Py、TyranoBuilder、WebGAL、BKE、Dialogic、Kirikiri 的横向对比：执行模型、脚本语言、图层架构、存档机制、资源管理、可扩展性 |
| [未来开发设计.md](未来开发设计.md) | 未来功能的完整设计草案（工具链、存档演进、UI 增强、模组规范、叙事图等）；其要点已整理为根目录的正式路线图 ROADMAP.md |

## 阅读建议

- 想快速理解引擎现状：先读根目录 README，再读 `项目分析.md`。
- 想写剧本：读根目录 `GalSGrammar.md`，参考 `scripts/demo/` 示例。
- 想参与开发：读 `架构及其优化方案.md` 了解分层约定，读根目录 `ROADMAP.md` 了解待做事项。
- 想了解设计动机：`架构评估与竞品对比分析.md` 记录了关键取舍的对比依据。
